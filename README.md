# Restaurant Check Calculator

A C# Windows Forms application that reads restaurant order data from a text file and calculates the final customer check.

## Features

- Reads ordered items from a text file
- Parses quantity, item name, and price
- Validates input data and file format
- Calculates individual item totals and subtotal
- Calculates 7% tax
- Supports multiple tip percentages
- Supports Cash, Credit Card, ATH Móvil, and Other payment methods
- Includes error handling for missing files and invalid input

## Technologies

- C#
- .NET Windows Forms
- File I/O
- Collections
- Input validation

## Skills Demonstrated

- File reading and parsing
- Input validation
- Exception handling
- Collections and calculations
- Event-driven desktop UI development
- Working with user-selected values and payment options

## Project Context

Academic programming project focused on building a functional desktop application that processes restaurant orders and calculates subtotal, tax, tip, and final amount due.
