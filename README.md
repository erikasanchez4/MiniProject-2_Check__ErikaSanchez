# Restaurant Check Calculator

A C# Windows Forms application that reads ordered items from a text file and calculates a restaurant bill including subtotal, tax, tip, and payment method.

## Features

- Reads order data from a text file
- Validates item quantities and prices
- Calculates item totals and subtotal
- Calculates 7% tax
- Supports multiple tip percentages
- Supports Cash, Credit Card, ATH Móvil, and Other payment methods
- Includes error handling for missing or invalid input

## Technologies

- C#
- .NET Windows Forms
- File I/O

## Skills Demonstrated

- Object-oriented programming fundamentals
- File reading and parsing
- Input validation
- Exception handling
- Collections and calculations
- Desktop UI event handling

## Project Context

Academic programming project focused on building a functional desktop application for processing restaurant orders and calculating a final check.
